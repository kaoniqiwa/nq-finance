# 💰 记账小工具

一个用 **Python + Streamlit + SQLite** 做的本地记账 Web 应用,完全离线运行,数据存在本机 `finance.db` 文件里。

## ✨ 功能

- **➕ 添加账目**:在表单里填金额、分类、日期、备注
- **📋 查看列表**:按月份/类型/分类筛选,表格展示
- **✏️ 编辑账目**:输入 ID 弹出编辑表单
- **🗑 删除账目**:输入 ID,二次确认后删除
- **📊 分类统计**:支出/收入按分类聚合,柱状图 + 统计表

## 🗂 预设分类

| 类型 | 分类                               |
|------|------------------------------------|
| 支出 | 餐饮、交通、购物、娱乐、居住、其他 |
| 收入 | 工资、奖金、红包、其他收入         |
| 转账 | 信用卡还款、余额转账               |

## 🚀 快速开始

需要 **Python 3.10+**,依赖用 [uv](https://docs.astral.sh/uv/) 管理。

```bash
# 1. 进入项目目录
cd nq-finance

# 2. 安装依赖(自动创建/复用 .venv,按 uv.lock 锁定版本)
uv sync

# 3. 启动应用
uv run streamlit run app.py 或者 make run 
```

浏览器会自动打开 `http://localhost:8503`,看到 3 个 tab 就成功了 🎉

## 🖱 操作指南

### 添加账目

1. 切到 **「➕ 添加」** tab
2. 选类型 (支出/收入/转账)
3. 选分类 (下拉框会根据类型自动过滤)
4. 填金额 (必须 > 0)、日期 (默认今天)、备注 (选填)
5. 点 **💾 保存** → 看到 ✓ 提示和气球动画就成功了
